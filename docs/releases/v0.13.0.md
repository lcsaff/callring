# v0.13.0

- 首页四个主页面支持左右滑动切换，保留各页滚动位置、搜索和沟通草稿；打开详情再返回可继续原来的阅读位置。
- 重设计通话记录与号码档案详情：通话列表显示姓名或号码、地区、职位和时间，支持直接播放录音、查看转写；号码详情分组展示号码信息、报表和分页通话记录，支持逐字段编辑。
- 系统录音可为全部已有可见通话补配，不再受自动导入天数或当前号码规则限制；仅在号码和开始时间能唯一对应时关联。没有对应通话的独立录音仍遵守原日期范围与号码规则。

验证范围：发布前执行最终提交的统一验证门、发布工具自检，以及 APK 版本、既有签名、摘要与对齐校验。首页与详情已有隔离模拟器回归证据；本轮没有在线 ADB 设备，未新增真实来电、厂商录音目录或后台自动调度验证，未调用付费模型。
