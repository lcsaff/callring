# v0.10.0

- 录音设置新增“系统录音自动导入天数”，默认最近 7 天，可填写正整数。按录音开始时间筛选，调整范围不删除已有录音，也不改变通话记录同步或显式手工文件导入。
- 支持 `姓名(号码)_yyyyMMddHHmmss` 及原有带日期时间分隔符的文件名；严格校验日期与设备时区，身份或关联有歧义时保留手工选择能力。
- 系统录音自动发现支持大目录和安装前的历史文件，不再受原有 500 项枚举失败及最近 12 小时已有档案候选的限制。没有对应通话时登记独立录音，不生成虚假的系统通话记录。
- 导入前进行稳定性观察，复制前后复核文件、设置及删除状态。持久来源身份避免重复建档、重复处理已完成分析或重新导入已删除录音；取消和应用恢复不会让迟到结果覆盖新状态。
- 本地发现可在离线时执行；转写、分析和档案补全仍遵循已有开关、目录授权及服务配置。修改导入天数不会自动开启分析或上传。
- 兼容旧录音设置及备份；恢复时保留去重与删除事实，清除目录授权和临时扫描信息。恢复后缺少音频的录音需显式重新选择文件，不会因重新授权目录而自动恢复付费处理。

本版 versionCode 为 22，录音数据库升级至 schema 6。支持同包名、同签名旧版本覆盖升级并保留数据；不支持通过安装旧 APK 降级数据库。

验证范围包含统一 JVM 测试、构建、双 lint、发布工具自检，以及发行 APK 的包名、版本、签名、对齐和附件摘要一致性检查。系统录音专项使用隔离模拟器、真实 SAF 读取和音频解码、合成目录及模拟 AI；未新增真实厂商录音目录、真实 SIM、厂商后台调度或真实在线 AI 服务验证。
