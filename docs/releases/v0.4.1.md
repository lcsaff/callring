# Callring v0.4.1

版本：0.4.1；versionCode：15。

本次包含两个修复：

- AI 与外观页面共用主题预设目录，可识别并切换联通红、天空蓝、青绿色；切换主题色时保留当前深浅模式。
- AI 沟通隐藏工具消息、成功读取记录及纯空白正文不再占用列表间距；按可见内容定位最新消息，保留错误/写入回执、最终回复和历史阅读位置。

沿用既有发行证书，可覆盖同签名的 0.4.0（versionCode 14）及兼容旧版，不需要清除应用数据。仍不能覆盖签名不同的历史 v0.2。

发布前的两项修复已经完成独立审查，1044 项 JVM 测试、构建、lint 和对应提交的 GitHub CI 均通过。发行候选还须在本版本最终提交上执行统一验证、签名、版本、包名、摘要和附件一致性校验。

本次未增加真实模型或真机来电验收；已有设备、待机与应用内更新限制不因打包发布而改变。修复细节见 [主题预设修复验收](../plans/AI主题预设修复验收.md) 和 [沟通空白修复验收](../plans/AI沟通空白修复验收.md)。
