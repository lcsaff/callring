# v0.9.0

- 移除来电及锁屏信息编辑弹窗、相关开关和专用组件。来电登记及已配置的录音转写、分析在后台执行，不弹出完成提示。
- 通话分析依据明确证据自动补全联系人空缺信息，新增自述职位、所属地区，保留姓名、部门、职位等现有字段，不新增单位字段。
- 已有非空信息保持不变；用户标记有异议后，可在后续通话中纠正，成功纠正后清除异议。手动编辑也会清除对应字段异议，无需额外确认流程。
- 防止旧分析覆盖手动编辑、删除后重建的联系人或更新后的信息；本地补全失败可重试，不重复请求已完成的付费分析。
- 不符合联系人号码格式的录音仍可转写及分析；联系人信息编辑入口说明限制。兼容旧数据与备份迁移。

本版继续使用 0.x 版本号，versionCode 为 21。支持同签名旧版本覆盖升级并保留数据，联系人数据库升级至 schema 4，不支持直接安装旧 APK 降级。旧来电弹窗方案已移除；后台分析继续遵循原有开关、权限及服务配置，不会自动启用上传。

发行验收覆盖统一 JVM 测试、构建、lint、隔离 backendQa 模拟器测试、发布工具自检及 APK 包名、版本、签名、对齐、附件摘要校验。未新增真实 SIM 来电、实体设备锁屏、长待机或真实模型服务验证。
