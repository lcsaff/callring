# Callring v0.4.0

版本：0.4.0；versionCode：14。

本次交付完成app / ui / backend分层整理及局部写入、刷新链路解耦，保留现有功能与持久数据读取语义。

- 局部操作改用窄查询与写入会话，减少依赖全量业务状态。
- 按变更范围累计失效并刷新，避免无关功能一起重载。
- AI工具改为具名操作，删除数字编号形成的内部隐式依赖。
- 删除BackendContext，改为显式窄能力装配；存储消费者不再通过具体类型强转穿透抽象。
- 整理模块内部目录，提取Android系统组件控制流程，删除迁移后的旧实现和兼容转发。
- 修复真机发现的SQLite局部列更新、白名单镜像同步及资源关闭问题，完善原生小组件测试截图和隔离下载验收工具。

沿用既有发行证书，可升级已安装的0.3.8/11及测试版0.3.10/13。本次包含较大架构调整并删除旧内部接口，使用0.x阶段的MINOR递增，版本定为0.4.0。公开最新版为0.3.8/11，测试版0.3.10/13已经分发，因此versionCode取14，确保高于全部已分发安装包；持久数据保持升级读取，无需清除数据。

已有验证记录包括1037项本地测试、后端31项和UI83项隔离真机测试，以及同证书覆盖升级、桌面组件、后台悬浮窗自检、重启和后台恢复检查。本次按用户要求不再重复CI或全套测试，仅打包并校验签名、版本和发布附件一致性。
