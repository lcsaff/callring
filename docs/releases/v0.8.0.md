# v0.8.0

- 录音列表改为摘要分页，旧归档索引分批准备，避免打开列表时读取全部转写与分析；列表和详情统一使用配置时区。
- 新增本地口令加密备份与全量恢复，可选择包含应用自有音频。恢复前校验并预览，恢复后暂停自动分析；API 密钥、系统权限、目录授权和组件绑定需重新配置。
- 新增存储占用统计与手动录音清理，支持日期和状态筛选、预览确认、取消及逐项结果；不自动删除旧录音，也不删除系统目录原文件。
- 新增可跳过的配置清单，首页仅在核心运行条件异常时显示检查入口。
- 完善备份、恢复、录音处理与清理的并发保护，防止旧任务迟到写入；备份复制期间允许来电登记继续写入。

本版继续使用 0.x 版本号。支持同签名旧版本覆盖升级并保留数据，versionCode 为 20。录音数据库升级至 schema 5，不支持直接安装旧 APK 降级。备份恢复是全量替换，请保管好备份口令；丢失口令无法恢复备份。

发行验收包括统一测试、构建、lint、发布工具自测，以及 APK 包名、版本、签名、对齐和附件摘要校验。当前没有在线设备，未新增真实来电、断电恢复、长待机或真实模型验证。
