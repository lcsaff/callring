# Callring v0.4.2

版本：0.4.2；versionCode：16。

- 亮屏锁屏时也可显示完整来电卡片。专用非导出 Activity 复用现有控制器和卡片，解锁后切回普通悬浮窗；息屏不主动点亮。
- 接听或结束后隐藏锁屏来电卡片；仍在编辑的草稿保留，解锁后可继续。窗口被系统关闭或压后台时有限恢复，避免无限争抢前台。
- 增加锁屏窗口生命周期与隔离设备测试，以及锁屏固定音频解码、模拟 AI、归档持久化设备检查。真实 SIM 双向采集、真实网络转写/分析与 JobScheduler 自动唤起仍须专项验证。

无需数据迁移。完整信息会在锁屏可见；设备仍需允许悬浮窗及厂商后台弹出/锁屏显示权限。沿用既有签名，不能覆盖签名不同的历史 v0.2。本任务不发布 GitHub Release，也不覆盖安装手机主包；最终验证结果见[锁屏来电验收记录](../plans/锁屏来电与录音链路验收.md)。
