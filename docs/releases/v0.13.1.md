# v0.13.1

- 应用更名为“扰喵簿”，采用暖橙底猫账本图标，并同步桌面小组件名称；包名、数据与升级签名保持兼容。
- 修复历史来电遗漏：授权后补齐手机系统仍保留的有效号码来电，不再被启用统计日期、暂停区间或当前号码规则挡住。历史展示与计分分开，不重算旧分数，也不重新创建已删除的号码历史；不导入呼出。
- 修复系统录音关联：兼容接听后才开始录音的时间差，多份录音对应同一通话时选择唯一最近的一份，并排除附近更近或并列的同号码呼出。支持带加号号码，保留歧义拒绝、已有关联与删除保护。

验证范围：发布前对最终提交执行统一验证门、发布工具自检，以及 APK 版本、既有签名、离线资源、摘要与 16 KiB 对齐校验。名称、图标和小组件已有隔离模拟器验证；历史导入与遗漏录音样本有前期隔离真机证据。真机随后离线，最终呼出排除修正及真实目录复测尚未完成；未覆盖生产安装，未调用付费模型。
