# 桌面快捷控制、即时外观与悬浮窗复测

## 用户已确定的行为

- 桌面小部件移除号码、档案、评分、报告与号码绑定流程。
- 展示免打扰开关，保留现有免打扰规则，关闭后重新开启恢复原模式。
- 点击“今日请假”直接按设备点击时的系统日期、时区创建当天全天请假。不进入应用，不显示日期选择、请假详情或管理入口。已有完整覆盖时不重复创建；成功反馈“今日已请假”。详情和撤销仍在应用内。
- 外观选择立即预览并自动保存，预设横排，显示模式紧随其后；自定义色和预览合并为紧凑区块，预览只服务自定义色；删除保存按钮。
- 提供无需来电历史的明确悬浮窗测试入口。权限不足时进入系统授权页；测试卡片不得产生通话、档案或白名单变更。

## 实现与边界

采用官方 Glance ActionCallback 与原生 Switch。所有小部件共同读取应用 API 的免打扰与请假状态，并随 API 变更、日期或时区变更刷新。跨实例串行请假读写，失败不得伪装成功。时间区间以相邻两天本地零点构造，兼容夏令时。

应用根级外观 ViewModel 保留即时选择与已提交状态；串行写入、合并滑块输入，后续选择不会被较早保存覆盖，失败提供原位重试。

悬浮窗沿用现有服务和窗口权限/锁屏规则。测试会话有独立标识、解释文本，仅提供窗口控制；明确区分 Android 悬浮窗权限和 HyperOS 后台弹出权限。设备上 QA 包的结果不能替代正式应用验证。

## 验收

模型测试覆盖系统日期切换、时区/夏令时、重复点击、读取失败与免打扰规则保留。真实 AppWidgetHost 验证两种尺寸、跨实例刷新、直接操作和主题。外观测试覆盖连续编辑、失败重试、即时主题与无保存按钮。悬浮窗测试覆盖权限分流、服务意图、只读测试卡片及真实窗口。
