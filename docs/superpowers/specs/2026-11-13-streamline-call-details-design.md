# 功能与通话详情整理

用户于 2026-11-13 确认推荐的分区阅读方案及配套功能清理范围。

## 已确认行为

- 转写统一使用随包本地模型。后台自动分析先本地转写再将文字送往分析服务；已有转写直接复用。移除云端音频上传、转写连接编辑、凭据、复制与测试入口，模型失败不得回退上传音频。保留当前十分钟限制和取消、删除、方向及 owner 隔离。
- 自动系统录音只匹配当前号码规则允许的已有可见通话，不限历史天数。删除独立录音按天数自动导入的路径及设置；无通话的音频仍可显式导入。保留来源去重、稳定性观察、歧义拒绝、删除墓碑及旧归档关联。
- 删除整个设置数据管理页、批量清理和临时全量档案重置的专用接口与实现。备份恢复、单号码删除、单录音删除、空间不足保护和共有恢复设施继续使用。
- 号码档案顶部保留通话记录图标及新增图标。职位管理只从设置进入。
- 通话详情采用身份摘要、录音、转写文本、AI 分析的顺序。事实紧凑排列，转写先预览后展开，摘要与待办先显示，档案建议及依据按需展开。导入、系统选择、刷新、删除放入更多菜单；导入统一为本地路径。错误留在对应分区，无音频时提供明确导入入口。

## 实现边界

ui 只消费 contracts；backend 统一业务与互斥；app 提供本地模型和平台存储。删除无消费者内部入口；旧持久字段只在必要编码解释器读取，不清库、不丢弃已有文本和分析。外部 AI 协议修改需逐项审查更新基线，不整表重生成。

## 验证

先补充后台不上传音频、旧配置兼容、历史关联与无关文件不导入的回归。UI 检查菜单、折叠、空状态、可访问图标、导航与状态恢复。执行项目统一门，按设备可用性补隔离设备；不得安装生产包或调用付费模型。
