# 来电静默整理与档案补全设计

日期：2026-11-03。状态：交互流程已采纳，待书面设计复核；尚未实现。

## 目标与流程

来电及通话期间不再自动展示编辑悬浮窗或锁屏编辑窗口。来电记录、筛选、铃声、统计及录音登记不依赖窗口或页面存活，息屏也使用同一后台流程，不主动亮屏。

通话结束后沿用可用录音关联、转写和自动分析流程。自动分析仍受现有录音、自动分析开关及连接配置控制，不因本次改动自动开启上传。没有录音时保留通话事实，不能生成虚构的通话内容。未接通电话也不推断身份。

分析完成后自动整理全文、摘要、身份信息与待办，按下述规则补全档案。完成不弹窗、不发完成通知；结果及失败状态在应用内查看。系统要求的录音前台服务通知仍按平台要求保留。

## 档案字段

| 字段 | 设计 |
| --- | --- |
| 姓名 | 复用现有字段。 |
| 单位 | 新增独立文本字段，记录所属组织。 |
| 部门 | 保留现有 department 字段，不把既有数据自动拆分或重解释为单位。 |
| 自述职位 | 新增文本字段，保存对方明确自述的职务。 |
| 所属地区 | 新增文本字段，保存对方所属单位或工作的明确地区，保留原文实际粒度。 |

自述职位与现有 positionId、职位级别和比较关系分开。自动补全不选择职位级别、不建立上下级关系、不修改白名单、免打扰、号码规则或评分策略。

地区必须有明确归属依据；临时出差地、谈论地点、服务对象所在地及号码归属地不能直接写为所属地区。不能将对方提到的第三人身份写入对方档案。无法明确归属、存在冲突或仅属模型推测的内容保留在分析结果，不自动写入。

旧数据原样保留，新字段迁移后为空。此前采纳分析时写入 department 的内容不自动搬迁；后续单位、部门分别提取和保存。所有新字段可在档案中手动编辑，并通过正式查询、命令及相关 AI 工具保持一致。

## 空缺与异议规则

默认只处理空缺字段；空串及纯空白文本视为空缺。非空且无异议的字段一律保留，包括先前由 AI 补全的值。

用户可按字段标记“有异议”。该标记只表示允许后续通话分析纠正，不立即清空原值、不触发额外模型请求。无异议为默认状态。

后续通话有明确原文依据时，可以纠正有异议字段；新值实际不同并成功提交后，将该字段标记为“无异议”。只有相同值、未提及、歧义、冲突或分析失败，均保留原值和异议状态。纠正不要求用户再次确认。

用户手动保存某字段的新内容时，将该字段标记为无异议；未修改的其他字段保持原状态。用户主动清空后，该字段按普通空缺处理，不新增禁止补全标记。

每个自动补全或纠正的字段保留来源通话、录音分析及原文依据，供用户查看和纠正；不扩展为额外的人工锁定、可信等级或逐次采纳机制。

## 一致性与职责

contracts 提供扩展档案、字段异议状态和来源的正式 DTO、查询与命令。backend 的档案业务入口统一实现字段资格判断和原子提交，录音分析流程复用该入口，页面和工具不复制补全规则。

app/data 负责数据库升级、字段与来源持久化；app/entrypoint 沿用录音任务生命周期及恢复机制。ui 的档案编辑器提供新字段与异议操作，录音详情展示分析结果、来源及处理状态。

写入时重新读取当前字段和值及版本：只有仍为空缺，或仍为本次分析所见的有异议字段，才能提交。用户在分析期间的修改或异议状态变化使旧结果对该字段失效；其他符合条件的字段仍可提交。并发分析不能覆盖较新提交。

同一分析结果重复执行不能重复修改或重复发布。删除档案或归档、取消任务和关闭 owner 后，迟到结果不能重新建档或写回。网络调用不跨数据库事务。

身份补全失败不影响已保存的通话记录和分析结果；应用内应能区分分析成功与档案补全失败。重试只补执行未完成的本地提交，不为补全失败重复上传或付费分析。

## 展示与兼容

档案列表、详情、编辑器及相关查询支持新增字段；搜索覆盖姓名、单位、部门、地区和自述职位。来源和异议状态在字段附近查看和操作，不要求每次通话后进入应用。

录音详情原“确认后采纳姓名和单位”流程改为展示自动补全结果及档案入口，不继续提供隐式覆盖已有无异议值的旧采纳路径；相关命令和 AI 工具同步迁移，外部协议变更需显式评审兼容性基线。

来电自动展示路径退役，删除失去消费者的弹窗接线及仅为自动弹窗服务的设置入口。桌面组件、档案手动编辑和业务统计保留；实施前核对悬浮窗预览与测试入口，避免保留已无产品用途的入口。

## 验证范围

- 字段：空缺补全、无依据不填、身份归属、地区语义、已有值保留、单位与部门分离、自述职位不影响级别与白名单。
- 异议：逐字段标记、后续通话纠正后清除标记、同值和失败保留标记、手动纠正与清空行为。
- 一致性：分析期间手动修改、并发分析、重复结果、删除后迟到结果、关闭与重启恢复、本地补全失败重试。
- 兼容：旧数据库升级保留 department/positionId 和分析历史，新字段默认空白，正式接口、工具目录和协议基线同步。
- 交互：亮屏、息屏、锁屏均不弹编辑窗；不发完成通知，应用内可查看结果和失败状态。
- 实施后运行统一验证门，按风险补隔离设备验证；真实 SIM、系统录音关联、后台自动调度及真实模型链路单独记录证据，模拟结果不能代替。
