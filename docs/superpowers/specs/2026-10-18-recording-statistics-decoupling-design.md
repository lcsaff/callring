# 录音与来电统计解除依赖

用户已授权解除录音对统计开关的依赖，范围以此前说明的这项功能耦合为准。

推荐独立来电登记：录音模块拥有来电身份、存储和列表，统计模块仅做可选关联。继续往统计数据库写不计数行虽然修改较少，但会保留生命周期和数据库依赖；拆进程则超出本次范围。

来电筛选入口发布观察事件，不等待录音存储，统计关闭也发布。录音登记和后续统计关联在独立串行执行器完成，录音故障或阻塞不能占用统计写入队列。录音开关关闭时不新建录音来电记录。

录音数据库新增事件表和可选统计关联表，事件以筛选 sessionId 幂等登记，号码/时间相同的不同会话仍分别留档。独立身份使用负数，旧统计归档的正数身份继续兼容；UI 将它们作为不透明的归档标识。事件和初始等待录音归档原子保存。数据库升级保留原录音、分析、配置和删除标记。

采集的活跃来电身份来自录音自己的登记，仍通过 RINGING/OFFHOOK/IDLE 状态防止错配拨出电话。统计同步隐藏或替换其明细不会影响录音身份。系统录音自动发现只扫描录音自己的事件及已有归档，不从统计明细生成新事件。

档案页面新增独立“通话录音”入口，列表读取录音归档，关闭统计也能查看、导入、分析、回听、删除。原报表入口通过可选关联打开同一份归档。删除、取消上传、迟到结果隔离继续生效。

验证覆盖：统计关闭仍发布观察事件且不写统计；录音观察阻塞/失败时统计照常完成；录音关闭不登记；独立身份幂等和跨会话区分；升级保留旧档案；不依赖统计库的登记、查询和列表；负数身份转写分析流程；独立 UI 入口。运行 backend/app/ui 全部测试、构建和 lint，设备离线时不宣称实机录音验收通过。
