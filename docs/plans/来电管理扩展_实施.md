# 来电管理扩展实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在独立 Android 应用中完成号码档案、可配置职位、节假日与请假、号码扣分制、免打扰、报表、悬浮窗及桌面组件，并验证息屏来电链路。

**Architecture:** Java 纯策略计算时间、职位关系、静音与评分；SQLite 保存档案、设置历史、日历、请假与通话明细。Telecom 回调及时响应系统，播放器、悬浮窗和通话记录同步分别管理生命周期，组件读取统一的统计结果。

**Tech Stack:** Java 8/Android 原生 View、SQLite、java.time、JUnit 4、现有 Gradle 7.5/AGP 7.3.1/SDK 33；本地 Telecom 模拟与真实手机检查。

项目无 Git 仓库，直接在用户指定目录实施，保留现有文件，不初始化 Git；新建和修改文件均可单独审查。已确认整个设计，无需再次等待执行方式选择。
