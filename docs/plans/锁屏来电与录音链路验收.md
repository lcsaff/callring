# 锁屏来电与录音链路验收

日期：2026-10-23。候选版本 0.4.2 / 16。用户确认锁屏显示完整来电卡片，并要求仅自动化测试，不安排人工接听或解锁。

## 实现范围

`ui/overlay` 的服务继续唯一持有 OverlayController、OverlaySessions 和业务订阅。亮屏锁屏时，非导出的 LockScreenOverlayActivity 复用 OverlayRoute；解锁后清除锁屏绑定并切回原 OverlayWindow。息屏不主动点亮。接听/结束隐藏锁屏卡片，已打开的编辑草稿保留到解锁后继续；服务销毁和会话失效清理绑定。Activity 实例回执与 LockScreenLaunchGate 为同一会话最多恢复三次、间隔至少两秒，不无限争抢系统前台。

录音、AI、存储、调度协议没有改变，无数据库迁移。运行状态页面补充小米后台弹出及锁屏显示权限说明。版本来源仅 version.properties。

- 最终功能代码 JVM：backend 369、UI 321、app 361，合计 1051；失败、错误、跳过均为零。contracts NO-SOURCE，不计为测试。
- 后端隔离真机既有测试 31/31 通过。仅安装 `com.greatwall.callring.backendqa`，未更改系统通话记录或主应用角色。
- 设备 Xiaomi 2410DPN6CC，Android 16 / API 36，HyperOS OS3.0。显式运行 `com.greatwall.callring.ui.lockeddevice.LockScreenOverlayDeviceTest`，1/1 通过：系统实际 keyguardLocked=true 时，向隔离 UI 包提交模拟响铃请求，锁屏 Activity 有焦点并显示；截图人工核对为完整卡片；模拟接听后会话和 Activity 关闭。数据为测试号码 100，没有拨打真实电话。
- 锁屏运行 `com.greatwall.callring.LockedRecordingPipelineDeviceTest`，1/1 通过：固定测试音频进入正式 RecordingAssembly/RecordingWorkflow，Android MediaMetadataRetriever、MediaExtractor/MediaCodec、PCM 转换和非静音检测实际执行；转写与分析使用固定 AiClient 回复；状态进入 COMPLETE，全文及姓名/单位/摘要写入真实 SQLite，关闭并重开后完全一致，锁屏下 Keystore 配置可读，重复处理未重复调用模拟 AI。
- 该测试从现成音频的 attachCapture 开始，**没有启动麦克风录制**。直接调用 runScheduled，**没有验证系统 JobScheduler 自动唤起**。未发送录音或文本至真实服务，未产生付费 AI 请求。
- 回归用例实际 RED：锁屏编辑来电卡片后接听，旧实现 host 仍非空；修正后隐藏窗口且保留编辑状态。服务所有权、解锁切回、息屏、销毁、失效 Activity 和有限恢复另有 JVM 覆盖。
- 普通 UI 真机全套本次未执行：完整构建期间设备自然锁屏，verify_ui.py 的“必须解锁”预检查失败。没有绕过该检查或自动解锁；专用锁屏用例由显式类名选择，不包含在默认套件扫描中。

## 小米权限发现

首次测试在安装后安全扫描期间授予权限，Settings.canDrawOverlays 仍为 false，未通过；等待扫描完成后该问题消失。随后后台弹出已允许，但锁屏 Activity 三次启动均被系统中止（result code=102），测试未通过。测试包的 MIUI app-op 10020 原为 ignore；临时允许后锁屏用例通过。

成功用例临时允许测试包 SYSTEM_ALERT_WINDOW、10021、10020，finally 已核对恢复原模式，并停止两个测试包。截图和原始日志只保存在本地 `build/qa/lockscreen/`，未发布。设备保持锁定，没有执行解锁命令或改变锁屏超时。

主包仍为原有 0.4.1 / 15，安装更新时间未变；只读检查发现主包 10020 与 10021 均为 ignore。因此即使升级新代码，也需要在手机应用权限中允许“锁屏显示”和“后台弹出界面”（名称依系统版本）；本任务未替用户修改主包权限。

## 完整链路与未验证项

| 环节 | 当前能力 | 本次证据与限制 |
| --- | --- | --- |
| 锁屏卡片 | 已实现专用窗口 | 实际锁屏、隔离包、模拟响铃通过；真实 SIM 入口及系统拨号器窗口竞争未测 |
| 真实通话录音 | 系统目录导入；实验性麦克风前台采集 | 仅源码和现有自动测试核查；未实录，不能保证双方音频或蓝牙/听筒效果 |
| 转写 | Android 解码后调用配置的兼容服务 | 真机锁屏解码通过；真实网络识别准确率、超时及服务兼容未测 |
| 分析 | 提取自述身份、依据、推测、摘要与待办 | 正式编排配模拟结果通过；真实模型质量未测 |
| 存档 | 真实 SQLite 全文及分析持久化，支持重试 | 真机锁屏写入、重开读回、重复处理不重复分析通过 |
| 更新号码档案 | 用户确认后采用自述姓名/单位 | 不全自动写入；职位及白名单不自动修改。本次未做锁屏真实 AI 后人工确认 |
| 自动后台执行 | 通话事件安排持久 Job、网络条件满足后处理 | 本次直接调用工作流；Doze、长待机、重启、强停恢复、系统自动调度未测 |

依赖条件：启用录音；有可用录音及授权；配置有效转写/分析服务；需要无人操作自动处理时启用 automaticAnalysis。首次开机未解锁前的数据访问仍不支持，由原有非 direct-boot 存储约束决定。不得把两项专用测试称为“锁屏真实通话到真实 AI 全链路通过”。
