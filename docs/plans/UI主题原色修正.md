# UI 主题原色修正

用户已确认：品牌强调与主按钮保留选择的原色；背景中性；文字及图标独立适配对比度。统一适用于三套预设、自定义颜色、深浅模式、页面、悬浮窗和小组件，评分语义保持独立。

## 设计

- `primaryFixed` 保存原始 RGB，`onPrimaryFixed` 选择对比度较高的黑/白文字，两种显示模式一致。
- `primary` 为中性表面上的可读强调色。原色可读时直接使用；否则仅调整明度，保留色相及尽可能多的饱和度。
- 表面、背景、卡片、边框采用统一中性色板，移除种子色向背景和容器的染色。
- 保留 Material 通用选中容器与未活动轨道的中性角色，不将原色填充全局套在 `secondaryContainer` 上，避免黑白主题的状态指示消失。
- 统一 `BrandButton` 使用固定原色角色；低对比原色补充边框。普通文字按钮、图标及小组件链接使用可读强调角色。
- 外观预览显示原始填充色。预设 ID、API、持久化值及评分配色均不变化；不保留旧柔和色板分支。

## 验证

2026-10-15：UI 本地 106 项、独立 UI 包设备 35 项、Backend 66 项、App 66 项及隔离 Backend QA 设备 31 项通过；Debug/Release/AndroidTest/Backend QA 构建与 App/UI Lint 通过。两个验证脚本退出 0。

11 项主题测试覆盖原色、背景中性、跨表面对比度、极端颜色、滑杆轨道与选中容器。原色/背景两项以及黑白控件两项均实际经历失败→修正→通过。共享像素测试对红、蓝、绿、黑、白各自的深浅模式采样实际主按钮填充，10 种组合均等于用户选择的 RGB；本地采用原生 Canvas，实机采用 PixelCopy。已查看实机正红白字按钮及中性深浅页面截图。
